# FolixMed

FolixMed is a corporate website for medical and natural care products.

This repository is intentionally kept minimal as a starting point for a future ASP.NET Core MVC and Razor Views application with a Web API and layered architecture.

Planned technology stack:
- ASP.NET Core MVC with Razor Views
- Web API
- C#
- .NET 10 LTS
- Layered architecture: WebUI, Api, Business, Core, Entities, DataAccess

The project will be implemented later using Codex, and the website design will be based on a commercially available HTML template selected after design approval.

This initial setup does not include application code, project files, solution structure, or frontend packages/templates.
